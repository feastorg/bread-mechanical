# Licensing

The designs and code in this repository are offered under either of two
licences, at your choice:

- [GPL-3.0-or-later](LICENSES/GPL-3.0-or-later.txt), or
- [CERN-OHL-S-2.0](LICENSES/CERN-OHL-S-2.0.txt)

SPDX expression: `GPL-3.0-or-later OR CERN-OHL-S-2.0`.

For OpenSCAD the `.scad` file is the hardware design source, and an STL or 3MF
is built from it, so the same choice covers the files you print. CERN-OHL-S-2.0
is written for physical products and how their source is made available;
GPL-3.0 is the more familiar choice when the files are treated as code.

## Exceptions

A file whose `SPDX-License-Identifier` header names a narrower licence is
offered under that licence only. Parts built on GPL-3.0 libraries, such as SBC
Case Builder, are `GPL-3.0-or-later` only, because their upstream does not grant
CERN-OHL-S.

## Files without a header

Data, configuration and documentation files carry no header. They are covered
by the repository-wide choice above.

The root [`LICENSE`](LICENSE) holds the GPL-3.0 text so that GitHub detects a
licence for the repository; it does not narrow the choice.
